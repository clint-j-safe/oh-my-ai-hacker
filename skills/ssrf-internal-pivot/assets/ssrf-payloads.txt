# SSRF probe targets. Loopback/IP-encoding bypasses point the target at its own
# internal surface; metadata entries use ONLY benign paths.
#
# SAFETY: the AWS IAM security-credentials path
#   (/latest/meta-data/iam/security-credentials/...) is intentionally EXCLUDED.
# Retrieving live cloud credentials is active credential theft and a separate,
# human-gated escalation -- this skill proves IMDS reachability with harmless
# paths (instance-id, the meta-data index) and stops there.
# file:// and gopher:// internal-exploitation schemes are intentionally absent.
#
# One payload per line; '#'/blank ignored. '{OOB}' is replaced with a per-test
# canary host for blind detection. For a broader manual set see SecLists SSRF.
